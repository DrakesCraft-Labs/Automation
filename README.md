# Automation

Addon de **Slimefun 4** que expande radicalmente las capacidades de automatización industrial mediante **androides programables avanzados, drones autónomos y computadoras de control logístico**. Portado y adaptado por **DrakesCraft Labs** para Paper/Purpur 1.21.11 en Java 21.

---

## 🎯 Objetivo

Facilitar la creación de fábricas inteligentes y cadenas de suministro autónomas, permitiendo delegar tareas repetitivas de minería, tala, recolección de cultivos y clasificación de inventarios a unidades robóticas eficientes.

---

## ⚡ Características Principales

- **Androides Programables de Nueva Generación**:
  - Unidades especializadas en minería de precisión, silvicultura, pesca y agricultura.
  - Scripts de comportamiento y filtros de inventario integrados.
- **Drones Autónomos**:
  - Drones aéreos de vigilancia, patrullaje y transporte ligero de ítems.
- **Computadoras y Terminales de Control**:
  - Monitoreo del estado de las máquinas y almacenamiento de rutinas de trabajo.
